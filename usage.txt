usage: realm.py [-h] [--version] [-v] [-s SETTINGS]
                {list,add,use,show,hide,remove} ...

Realm changing module for World of Warcraft

optional arguments:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  -v, --verbose         increase verbosity level. Quiet by default.
  -s SETTINGS, --settings SETTINGS
                        use settings from a .json file. File "realm.json" is
                        used as default

Commands:
  main settings interface

  {list,add,use,show,hide,remove}
    list                list realms
    add                 add new realm or change existing
    use                 use realm by name
    show                show hidden realms
    hide                hide realms
    remove              remove realms

usage: realm.py list [-h] [-l] [--all | --hidden]

optional arguments:
  -h, --help  show this help message and exit
  -l, --long  list full information, not only names
  --all       list all realms, including hidden
  --hidden    list hidden realms only

usage: realm.py add [-h] [-f] name [strings [strings ...]]

positional arguments:
  name         name for new or existing realm to add or change.
  strings      strings for realmlist.wtf file. Asked from standard input if
               omit

optional arguments:
  -h, --help   show this help message and exit
  -f, --force  force change existing realm, no prompt

usage: realm.py use [-h] name

positional arguments:
  name        name of chosen realm. Use "list" to choose

optional arguments:
  -h, --help  show this help message and exit

usage: realm.py show [-h] [names ...]

positional arguments:
  names       name of hidden realm to show. Use "list" to choose

optional arguments:
  -h, --help  show this help message and exit

usage: realm.py hide [-h] [names ...]

positional arguments:
  names       name of realm to hide. Use "list" to choose

optional arguments:
  -h, --help  show this help message and exit

usage: realm.py remove [-h] [-f] [names ...]

positional arguments:
  names        name of realm to permanently delete. Use "list" to choose

optional arguments:
  -h, --help   show this help message and exit
  -f, --force  force deletion operation, no prompt
